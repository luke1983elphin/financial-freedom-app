# Saved Scenarios calculation support

Stacked on the preceding calculation-support drafts. Downloads are attached to the specific snapshot viewer, current-plan comparison and saved-snapshot comparison. Reopened retirement calculations continue to use the retirement export, now explicitly identified as saved retirement inputs recalculated with the current engine.

Historical snapshots export only retained data. Missing annual workings are labelled **Workings unavailable for this snapshot**; no present-day engine rerun is substituted. Retained text-only figures remain text, with unavailable numeric differences. Current-plan comparisons capture both sources, their displayed values and genuine plan-input differences, excluding metadata through the existing financial-difference filter. Numeric differences are saved minus current, including negatives and zero.

The workbook includes source labels, stable SAV references, periods/units, original values, selected-basis values, actual displayed text, reconciliation, separate conversion formulas, retained inputs/workings and review status. Historical storage and schemas are unchanged. The saved viewer has no existing PDF export, so the example uses a matching screenshot and ID.

Validation: fictional incomplete snapshot versus a materially different current plan, both dollar bases, historical retirement snapshot, reopen and history preservation; 41 saved-card/mobile snapshot regression checks and 38 report checks; Excel formula recalculation and a disposable input perturbation. Examples and repeatable browser/Excel scripts are included. Keep draft; no merge or deployment.
