# R6B Legacy Compatibility

- Plans with no `incomeItems` array continue to use valid legacy person frequency fields.
- Empty structured arrays continue to use the legacy fallback.
- A structured salary with a blank or malformed frequency does not suppress a valid legacy frequency.
- If neither source is usable, the existing fortnightly default applies.
- Legacy fields are read only and are never rewritten to match canonical data.
- Existing Weekly Plan timing rows without reliable generated provenance are preserved exactly rather than guessed to be auto-generated.
- The aggregate legacy other-income row is unchanged.

Tests R6B-H and R6B-I cover the fallback paths. The saved-row compatibility test proves an old row without `autoGenerated`, `sourceKind` and `sourceSnapshot` evidence is not rewritten.
