# R6B Weekly Plan History Preservation

New salary timing rows are tagged with:

- stable timing-row ID;
- canonical income `sourceId` where available;
- `sourceKind: "income"`;
- `autoGenerated: true`;
- an exact `sourceSnapshot`.

On reforecast, a canonical source/frequency change may update a row only when it still matches its source snapshot, is not marked edited, and has no active occurrence override. The updated row is flagged for timing review.

The following remain untouched:

- legacy saved rows without proof of generated ownership;
- manually edited frequency, amount or first-date rows;
- split/replacement series and other edit-provenance rows;
- occurrence-edited rows;
- completed week objects, including their planned and actual history;
- recorded actual values on incomplete weeks.

Completed weeks continue through the existing frozen-week path. Future eligible generated rows are recalculated using existing R3B reforecast semantics. No Financial Plan data is mutated.
