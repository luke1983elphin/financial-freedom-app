# R5 Policy and Consent Scaffolding

Footer links open accessible Privacy and Terms dialogs for `#privacy` and `#terms`. Both deliberately show `TODO: legal copy pending professional review` and state that the content is not approved. R5 does not draft legal terms.

AI remains disabled by the exact R1 server flag. The future client flow now requires two affirmative, unticked acknowledgements: the existing educational-information acknowledgement and a separate data-transfer consent placeholder. The generation function checks both before making a request. This client state is a UX gate only and is not represented as endpoint authentication or R4B abuse protection.

Ordinary planning does not require AI consent. No AI setting was enabled and no production configuration was changed.
