# R6A Stage Taxonomy

## Financial Stage

Authoritative financial classification from `financialStageInfo()`:

1. Building the Foundation
2. Building Wealth
3. Financial Independence
4. Financial Freedom

Used by Dashboard, Reports, Setup summary and Wizard result summaries when they state `Financial Stage` or `Current stage`. Existing thresholds are unchanged.

## Financial Journey Step

Behavioral/coaching sequence from `engagementStageInfo()`:

1. Getting Started
2. Building Stability
3. Emergency Ready
4. Reducing Debt
5. Building Wealth
6. Growing Investment Income
7. Approaching Independence
8. Financial Independence
9. Financial Freedom

Used by Home and the full journey map. Visible labels now say `Current journey step` or `Financial Journey Step`.

The values may legitimately differ. For Young Professional, the formal Financial Stage is `Building the Foundation`, while the Financial Journey Step is `Building Wealth` because the plan already contains investments. No threshold was changed to force equality.
