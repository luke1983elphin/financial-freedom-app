# Financial Freedom

Financial Freedom is an Australian financial planning and retirement modelling web application designed to help users explore how income, spending, investments, superannuation, debt, property and retirement timing may affect their future financial position.

## Key features

- Financial position and cashflow modelling
- Investment and superannuation projections
- Financial independence progress tracking
- Semi-retirement and retirement scenario modelling
- Year-by-year retirement projections
- Debt, mortgage and offset modelling
- Rental and investment property modelling
- One-off lifestyle spending scenarios
- Saved and comparison scenarios
- Decision modelling and what-if analysis

## Important information

Financial Freedom provides financial modelling and scenario estimates based on the information and assumptions entered. Results are illustrative and are not guaranteed outcomes.

The application does not replace professional financial, taxation or legal advice. Users should consider obtaining appropriately qualified advice before making important financial decisions.
